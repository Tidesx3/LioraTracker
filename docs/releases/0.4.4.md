## English

Any AI can now write routines for you: ask Claude, ChatGPT or another for a plan, and Liora imports it. A single routine or a whole program in a rotation, with supersets, rep ranges, progression and exercises of its own.

- On the Train tab, the new import button opens a file, takes a pasted answer, or copies Liora's format for your AI to read first. Sharing an AI's answer to Liora works too.
- Before anything is saved, you see what's in it and which exercise each name becomes, and can change it. A file with mistakes lists them, ready to copy back to the AI.
- For AI tools on a computer (Claude Code, Codex, Gemini CLI and others), the routine tool in Liora's repository searches the exercise catalog, checks the file, and can read your backup so the weights fit you.

## Deutsch

Jede KI kann jetzt Routinen für dich schreiben: Bitte Claude, ChatGPT oder eine andere um einen Plan, und Liora importiert ihn. Eine einzelne Routine oder ein ganzes Programm als Rotation, mit Supersätzen, Spannen, Progression und eigenen Übungen.

- Im Training öffnet der neue Import-Knopf eine Datei, nimmt eine eingefügte Antwort oder kopiert Lioras Format, damit deine KI es vorher liest. Du kannst die Antwort der KI auch direkt mit Liora teilen.
- Bevor etwas gespeichert wird, siehst du, was drinsteckt und welche Übung aus jedem Namen wird, und kannst es ändern. Hat die Datei Fehler, stehen sie da, bereit zum Zurückkopieren an die KI.
- Für KI-Werkzeuge am Rechner (Claude Code, Codex, Gemini CLI und andere) durchsucht das Routinen-Tool in Lioras Repository den Übungskatalog, prüft die Datei und kann dein Backup lesen, damit die Gewichte zu dir passen.
